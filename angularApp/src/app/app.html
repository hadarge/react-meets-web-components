❤️ Example 2: React Component as Web Component

The <like-button> is a React component wrapped as a web component. Notice how we use #likeBtn template reference and @ViewChild to set the onLikeChange callback in the TypeScript file.

Current count: {{ likeCount }}

💡 Angular Integration Notes
  • [likeCount]="likeCount" - Reactive attribute binding (number converted to string)
  • #likeBtn - Template reference variable for DOM access
  • @ViewChild('likeBtn') - Gets ElementRef in component class
  • Function callbacks are set in ngAfterViewInit(): this.likeBtn.nativeElement.onLikeChange = ...
  • The web component converts the string "likeCount" back to a number internally
  • Unlike Vue, Angular doesn't have a .prop modifier - use ViewChild instead

Exercise 2: Understand Angular's ViewChild Pattern

Angular requires a different approach than Vue for setting function properties:

  1. Add a template reference in HTML: #myElement
  2. Get the reference in TypeScript: @ViewChild('myElement') myElement!: ElementRef;
  3. Set the property in ngAfterViewInit(): this.myElement.nativeElement.onEvent = this.handler.bind(this);

Why is this necessary?

  • HTML attributes can only be strings
  • Function properties must be set via JavaScript
  • Angular provides ViewChild for direct DOM access
